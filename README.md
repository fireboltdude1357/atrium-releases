# Atrium for Mac

Signed and notarized builds of the Atrium desktop app, for Apple Silicon and Intel.

Download the DMG from the [latest release](https://github.com/fireboltdude1357/atrium-releases/releases/latest), open it, and drag Atrium to Applications. Installed copies check this repo hourly and update themselves.

Stable releases are marked latest. Previews are prereleases, and only copies installed from a preview follow them.

This repo holds release files only. A release workflow in Atrium's private source repo publishes them.
